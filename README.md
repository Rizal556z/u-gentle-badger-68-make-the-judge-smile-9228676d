A free entry for the [Make the Judge Smile](https://make.fun/competitions/u-gentle-badger-68-make-the-judge-smile-9228676d) competition on make.fun.

## Entry

> This morning a street cat stole my fried fish, then purred against my leg like it owed me rent — and somehow I felt paid in full.

## How it works

`main.py` (pure Python standard library, no dependencies) writes the one-line
entry above to `/output/entry.txt` — one line, at most 200 characters, about a
small good thing that happened today.

Run it:

```sh
python3 main.py
```
